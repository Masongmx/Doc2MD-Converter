# 部署指南：一键安装版 / 精简版 / 断网便携版

Doc2MD Converter 提供三种部署形态，按使用场景选择：

| 形态 | 适用场景 | 体积 | 旧格式 .doc/.xls/.ppt | 扫描 PDF OCR |
|------|----------|------|----------------------|--------------|
| **一键安装版**（推荐） | 想省事、功能全开 | 约 535MB | ✅ 内置 | ✅ 内置 |
| **精简版**（单 exe） | 日常转换、快速分发 | 约 174MB | ❌ 需外部工具 | ❌ 需外部工具 |
| **断网便携版** | 完全离线内网机器 | 1GB+ | ✅ 内置 | ✅ 内置 |

---

## 一、一键安装版（推荐）

**一个安装包，双击安装，所有引擎内置，无需任何额外配置。**

- 下载 `Doc2MD-Converter-1.0.0-Setup.exe`（约 535MB，LZMA2 压缩）
- 双击运行安装向导：Next → Install → Finish 三步完成
- 默认安装到 `C:\Program Files\Doc2MD-Converter`，桌面自动创建快捷方式
- 内置组件（免单独安装）：
  - **LibreOffice 26.2**：旧式 .doc / .xls / .ppt 转换引擎
  - **OCRmyPDF 17.7 + Tesseract 5.4（含简体中文）**：扫描版 PDF OCR
- 安装后即拥有全部功能：PDF/DOCX/XLSX/PPTX/MD 转换、公文排版、旧格式转换、扫描 OCR

> 提示：安装向导为英文界面（标准 Next / Install / Finish），无数字签名，Windows SmartScreen 提示"未知发布者"时选择"仍要运行"即可。

### 校验安装包完整性（可选）

```powershell
Get-FileHash "Doc2MD-Converter-1.0.0-Setup.exe" -Algorithm SHA256
# 期望值：8D1FA43F57E95D95B0D9DE5255A7AA3C87E984E857A0006E22F91A1BDE6B0003
```

### 卸载

控制面板 → 程序和功能 → 找到 "Doc2MD Converter" → 卸载，或运行安装目录下的 `unins000.exe`。

## 二、精简版（单 exe，零依赖）

**仅一个 exe 文件，下载即用。**

- 下载 `Doc2MD.Converter.exe`（约 174MB，自包含免安装 .NET）
- 双击运行，直接拖入文档即可

**已覆盖的功能**（无需任何外部工具）：

| 功能 | 支持 |
|------|------|
| PDF（有文字层）→ Markdown | ✅ |
| DOCX / XLSX / PPTX → Markdown | ✅ |
| TXT / MD → Markdown | ✅ |
| Markdown → 公文 DOCX（GB/T 9704） | ✅ |
| DOCX 一键规范排版 | ✅ |
| .doc / .xls / .ppt（旧格式）→ Markdown | ❌ 需 LibreOffice |
| 扫描版 PDF（无文字层）OCR | ❌ 需 OCRmyPDF + Tesseract |

> 精简版满足日常 80% 场景。遇到 ❌ 功能时程序会给出明确提示，其余功能不受影响。

### 用精简版补全完整功能（手动装依赖）

在**可上网的机器**上按以下指引安装，程序自动识别（无需改配置）：

1. **LibreOffice**（旧式 .doc/.xls/.ppt 转换）
   - 官方下载：https://www.libreoffice.org/download/download-libreoffice/
   - 或国内镜像：https://mirrors.tuna.tsinghua.edu.cn/libreoffice/libreoffice/stable/
   - 下载 Windows x86_64 版安装包，默认安装即可

2. **Tesseract OCR**（文字识别引擎，含中文）
   - 官方 Windows 安装包（UB-Mannheim 版）：https://github.com/UB-Mannheim/tesseract/wiki
   - 安装时勾选 **Simplified Chinese (chi_sim)** 语言包
   - 默认安装位置：`C:\Program Files\Tesseract-OCR\`

3. **OCRmyPDF**（OCR 管线，Python 包）
   ```powershell
   # 安装 Python 3（https://www.python.org/downloads/），安装时勾选 "Add to PATH"
   pip install ocrmypdf
   ```

> 程序自动探测以上工具的常见安装位置与 PATH，无需手动配置。

## 三、断网/内网场景（便携包兜底）

完全断网的机器，可放 `tools/` 目录随程序使用（全部免安装、离线）：

```text
目标目录/
├── Doc2MD.Converter.exe
└── tools/
    ├── LibreOffice/          # .doc/.xls/.ppt 转换（约 660MB）
    └── OCRmyPDF/ 或 OCRmyPDF-slim/   # 扫描 PDF OCR（约 300-990MB）
```

在可上网的机器制作便携包后，通过 U 盘 / 共享盘拷贝到内网机器。

## 四、验证清单

安装完成后，建议按以下顺序验证：

- [ ] 拖入 `.docx` / `.pdf`（有文字层）→ 应正常转换（精简版即可）
- [ ] 拖入 `.doc` / `.xls` / `.ppt` → 完整版/便携版应能转换
- [ ] 拖入扫描版 PDF → 完整版/便携版应能 OCR 出文字

## 五、故障排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 提示"未找到 LibreOffice" | 未装 LibreOffice 且无 tools 便携包 | 装一键安装版 / 官方版 / 放便携包 |
| 提示"未找到 OCRmyPDF" | 未装 ocrmypdf 且无 tools 便携包 | `pip install ocrmypdf` 或放便携包 |
| OCR 报错语言包缺失 | Tesseract 未装 chi_sim | 重装 Tesseract 勾选简体中文 |
| 首次转换较慢（10-30 秒） | LibreOffice 首次初始化配置 | 正常现象，之后加快 |
| SmartScreen 提示未知发布者 | 安装包未做数字签名 | 选择"仍要运行" |
