# 内网离线部署指南（绿色便携版）

本文档面向**完全离线内网环境**，无需安装任何软件即可使用 Doc2MD Converter 的全部功能。

## 一、部署内容

将以下内容拷贝到目标机器（可放 U 盘 / 共享盘分发）：

```text
目标目录/
├── Doc2MD.Converter.exe        # 主程序（约 174MB，免安装 .NET）
└── tools/                      # 可选外部引擎（全部免安装）
    ├── LibreOffice/            # 旧式 .doc/.xls/.ppt 转换引擎（约 660MB）
    ├── OCRmyPDF/               # OCR 完整版：内置 Python + Tesseract（约 990MB）
    └── OCRmyPDF-slim/          # OCR 精简版：内置 Tesseract（约 300MB）
```

## 二、三种部署方案选择

| 方案 | 包含 | 体积 | 适用场景 |
|------|------|------|----------|
| 完整版 | exe + LibreOffice + OCRmyPDF | 约 1.7GB | 功能全开，推荐 |
| 精简版 | exe + LibreOffice + OCRmyPDF-slim | 约 1.0GB | 空间有限的机器 |
| 基础版 | 仅 exe | 174MB | 只转现代格式（PDF/DOCX/XLSX/PPTX），不需要旧式格式与扫描 OCR |

> OCR 引擎二选一即可：`OCRmyPDF`（完整版）与 `OCRmyPDF-slim`（精简版）程序自动识别，
> 两者都放时优先使用完整版。两个都不放时，仅"扫描型 PDF 的 OCR 识别"不可用，
> 其余功能（含普通 PDF 文本提取）完全正常。

## 三、部署步骤

1. 将 `Doc2MD.Converter.exe` 与 `tools/` 目录放在同一目录下
2. 双击运行 `Doc2MD.Converter.exe`
3. 直接拖入文档即可使用

无需安装、无需注册表、无需管理员权限、全程离线。

## 四、验证清单

部署完成后，可快速验证：

- [ ] 拖入一个 `.doc` / `.xls` / `.ppt` 文件 → 应能正常转换（LibreOffice 生效）
- [ ] 拖入一个扫描版 PDF（无文字层）→ 应能 OCR 识别出文字（OCR 引擎生效）
- [ ] 拖入 `.docx` / `.pdf`（有文字层）→ 应正常转换（无需外部引擎）

## 五、故障排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 提示"未找到 LibreOffice" | `tools/LibreOffice/` 缺失或路径不对 | 确认与 exe 同级目录下有 `tools/LibreOffice/program/soffice.com` |
| 提示"未找到 OCRmyPDF" | `tools/OCRmyPDF` 与 `tools/OCRmyPDF-slim` 均缺失 | 放入任一 OCR 包 |
| OCR 报错"未找到 chi_sim 语言包" | 内置语言包不完整 | 确认 `tools/OCRmyPDF/tesseract/tessdata/chi_sim.traineddata` 存在 |
| 首次转换较慢（10-30 秒） | LibreOffice 首次初始化配置 | 属正常现象，之后会加快 |

## 六、环境变量（高级）

以下环境变量可覆盖默认探测路径（不设置时自动查找 `tools/`）：

- `DOC2MD_LIBREOFFICE_PATH`：soffice.com 或 soffice.exe 的绝对路径
- `DOC2MD_OCRMYPDF_PATH`：ocrmypdf.exe 的绝对路径
