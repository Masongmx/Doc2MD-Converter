# 部署指南：精简版 / 完整版 / 断网便携版

Doc2MD Converter 采用「精简版优先」的部署策略，按需选择：

## 一、精简版（推荐，默认）

**仅一个 exe 文件，下载即用，零依赖。**

- 下载 `Doc2MD.Converter.exe`（约 174MB，自包含免安装 .NET）
- 双击运行，直接拖入文档即可

**已覆盖的功能**（无需任何外部工具）：

| 功能 | 支持 |
|------|------|
| PDF（有文字层）→ Markdown | ✅ |
| DOCX / XLSX / PPTX → Markdown | ✅ |
| TXT / MD → Markdown | ✅ |
| Markdown → 公文 DOCX（GB/T 9704） | ✅ |
| DOCX 一键规范排版 | ✅ |
| .doc / .xls / .ppt（旧格式）→ Markdown | ❌ 需 LibreOffice |
| 扫描版 PDF（无文字层）OCR | ❌ 需 OCRmyPDF + Tesseract |

> 精简版满足日常 80% 场景。遇到上述 ❌ 功能时，程序会给出明确提示，其余功能不受影响。

## 二、完整版（外网安装官方依赖）

在**可上网的机器**上按以下指引安装，程序自动识别（无需改配置）：

### 1. LibreOffice（旧式 .doc/.xls/.ppt 转换，约 350MB）

- 官方下载：https://www.libreoffice.org/download/download-libreoffice/
- 或国内镜像：https://mirrors.tuna.tsinghua.edu.cn/libreoffice/libreoffice/stable/
- 下载 Windows x86_64 版安装包，默认安装即可

### 2. Tesseract OCR（文字识别引擎，含中文）

- 官方 Windows 安装包（UB-Mannheim 版）：https://github.com/UB-Mannheim/tesseract/wiki
- 安装时勾选 **Simplified Chinese (chi_sim)** 语言包
- 安装后默认位置：`C:\Program Files\Tesseract-OCR\`

### 3. OCRmyPDF（OCR 管线，Python 包）

```powershell
# 安装 Python 3（https://www.python.org/downloads/），安装时勾选 "Add to PATH"
pip install ocrmypdf
```

> 程序自动探测以上工具的常见安装位置与 PATH，无需手动配置。

## 三、断网/内网场景（便携包兜底）

完全断网的机器，可放 `tools/` 目录随程序使用（全部免安装、离线）：

```text
目标目录/
├── Doc2MD.Converter.exe
└── tools/
    ├── LibreOffice/          # .doc/.xls/.ppt 转换（约 660MB）
    └── OCRmyPDF/ 或 OCRmyPDF-slim/   # 扫描 PDF OCR（约 300-990MB）
```

在可上网的机器制作便携包后，通过 U 盘 / 共享盘拷贝到内网机器。

## 四、验证清单

- [ ] 拖入 `.docx` / `.pdf`（有文字层）→ 应正常转换（精简版即可）
- [ ] 拖入 `.doc` / `.xls` / `.ppt` → 完整版/便携版应能转换
- [ ] 拖入扫描版 PDF → 完整版/便携版应能 OCR 出文字

## 五、故障排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 提示"未找到 LibreOffice" | 未装 LibreOffice 且无 tools 便携包 | 安装官方版或放便携包 |
| 提示"未找到 OCRmyPDF" | 未装 ocrmypdf 且无 tools 便携包 | `pip install ocrmypdf` 或放便携包 |
| OCR 报错语言包缺失 | Tesseract 未装 chi_sim | 重装 Tesseract 勾选简体中文 |
| 首次转换较慢（10-30 秒） | LibreOffice 首次初始化配置 | 正常现象，之后加快 |

## 六、环境变量（高级）

- `DOC2MD_LIBREOFFICE_PATH`：soffice.com / soffice.exe 绝对路径
- `DOC2MD_OCRMYPDF_PATH`：ocrmypdf.exe 绝对路径
